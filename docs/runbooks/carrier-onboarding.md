# Carrier onboarding

**Owner:** platform operator and voice on-call. Keep live dialing and inbound admission disabled until the carrier-specific signature, media and callback checks have been independently certified. Fixture calls never dial.

1. Install the approved carrier plugin and create a provider credential and binding in the operator console. The binding belongs to one workspace and its secret value is never copied into a release.
2. Set `OVO_MEDIA_PUBLIC_BASE_URL` to the exact public HTTPS origin and retain `OVO_INBOUND_ROUTE_SECRET` as an installation secret. The gateway uses a WSS media endpoint derived from that origin. Validate public routing and TLS separately from local fixtures.
3. As an administrator, call `GET /v1/provider-bindings/:id/carrier-urls` and paste only the returned URLs into the carrier application. They are signed, binding-scoped operator URLs. Do not rebuild their query strings, append a second query or substitute another hostname/port: signature verification uses the raw external URL.
4. Select the carrier and its binding on an agent release. Run compatibility and fixture calls. Review speech, callback, routing and cost evidence. Enable a real carrier only after the founder authorizes the vendor sandbox or owned-number test.
