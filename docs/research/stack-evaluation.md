# Initial stack evaluation

Date: 2026-09-20. Source audit complete; performance and live certification pending.

| Area                   | Implementation choice                                                             | Evidence and alternatives                                                                                                                | Remaining gate                                               |
| ---------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Runtime                | Node 22.21.0 / strict TypeScript 6.0.3 / pnpm 10.23.0                             | Available toolchain; DeepSeek supports Node >=22.19.0. First-party packages private and namespaced.                                      | Clean checkout full build                                    |
| Plugin foundation      | Traceable DeepSeek extraction with patched Cordis                                 | [Import map](deepseek-import-map.md), retained tests                                                                                     | Full application conformance                                 |
| Voice                  | Focused plugin and real LiveKit comparative spikes                                | [Source audit](voice-upstreams.md)                                                                                                       | Matched audio/carrier benchmarks; no final production choice |
| Inference              | AI SDK single-step provider adapter candidate                                     | Actual streaming/abort and usage source inspected; no autonomous SDK tool executor                                                       | Authorized provider fixture                                  |
| API                    | Fastify                                                                           | Small explicit API plugin and route schemas suit independent control plane; NestJS adds a second DI framework                            | API integration/security tests                               |
| Console                | Next.js / React                                                                   | Required full studio and route-based operations; design uses accessible native controls                                                  | Browser journeys and production build                        |
| Validation             | Zod configuration + JSON Schema/Ajv tool/config validation                        | Shared runtime schemas; no model-only permission enforcement                                                                             | Schema drift and negative fixtures                           |
| Data                   | Relational durable records; SQLite local profile; PostgreSQL orchestration target | Transactions/conditional ownership support immutable releases and operation identity; DynamoDB would require separate search projections | Unified production storage, restore and search benchmark     |
| Jobs/artifacts/secrets | SQS / S3 / Secrets Manager production adapters                                    | AWS external managed services explicit; local adapters are not AWS proof                                                                 | Authorized staging tests                                     |

The SQLite local profile persists data to disk and is not a distributed Fargate store. A production release must use a shared durable database for every control and worker record. No two-store synchronization system is selected.
